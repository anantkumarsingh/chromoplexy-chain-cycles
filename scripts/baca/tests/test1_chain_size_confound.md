# Test 1: Chain-Size Confound Check

**Script:** `test1_chain_size_confound.py`
**Output:** `results/stat_test1_chain_size_confound.csv`

## 1. What the test is

We just finished Phase 3, which showed that "obligate" and "probable" cycle
completion (Phase 2's invented-edge closure) recover a lot more chromoplexy
calls than real (observed) data alone does (21/50 and 24/50 patients vs.
just 4/50 real). Before trusting that recovery as a meaningful finding, we
wanted to rule out an obvious alternative explanation: maybe those extra
chromoplexy calls aren't telling us anything new about biology — maybe
they're just showing up on chains that were already bigger to begin with,
since a bigger chain naturally has more room for invented edges to build a
large closed structure.

So this test asks a narrower, mechanical question: **among chains that real
data does NOT already call chromoplexy-positive, does the chain's size
predict whether obligate/probable completion pushes it over the line into
"qualifies for chromoplexy"?**

We chose the Mann-Whitney U test (rather than a t-test) because the
variables involved — number of rearrangements, number of dangling ends,
number of chromosomes touched — are small non-negative integer counts, not
normally distributed, and the two groups being compared are very unequal in
size (e.g. 31 vs. 319 chains). Mann-Whitney doesn't assume normality or
equal variance, which a t-test does. We paired it with rank-biserial
correlation as an effect size, since a p-value alone tells you "is there
probably a difference" but not "how big is it."

We also ran one Spearman rank correlation (not a group comparison) as a
companion check, for the same reason (count data, not normally distributed).

## 2. What the test does

For every chain in `results/phase2_obligate_probable_completion.csv` that
Phase 2 was able to enumerate (354 of 366 — the other 12 have too many
dangling ends to enumerate and are excluded, not guessed at):

- Split chains into two groups based on whether they qualify for
  chromoplexy under a given completion lens (`obligate` or `probable`) at a
  given threshold (`strict` = closed cycle spans ≥3 chromosomes, `loose` =
  ≥2), restricted to chains that do NOT already qualify from real data
  alone.
- Compare chain-size variables (`n_dangling_ends`, `n_rearrangements`,
  `k_chromosomes_whole_chain`) between the two groups with a Mann-Whitney U
  test.
- Separately, correlate `n_dangling_ends` against the largest chromosome
  span the completion actually achieved, across all enumerable chains, with
  Spearman's rho.

## 3. CSV column reference

## 4. Step-by-step: what the test does

1. Load `results/phase2_obligate_probable_completion.csv` (366 chains).
2. Keep only the 354 chains where `phase2_enumerable == True`.
3. For each threshold (`strict`, `loose`):
   a. Restrict to chains where `real_has_chromoplexy_<threshold> == False`.
   b. For each lens (`obligate`, `probable`):
      - Split into "qualifies" (`<lens>_has_chromoplexy_<threshold> == True`) vs. "does not qualify" (`== False`).
      - For each of the 3 size variables, run Mann-Whitney U comparing the two groups, and compute rank-biserial effect size.
4. Separately, across all 354 enumerable chains (no group split), correlate `n_dangling_ends` against `obligate_max_cycle_chrom_span` and `probable_max_cycle_chrom_span` with Spearman's rho.
5. Write every test's inputs/outputs as one row to the output CSV.

## 5. Limitations and Notes

- Restricted to the 354/366 enumerable chains; the 12 non-enumerable chains (>12 dangling ends) are excluded from every comparison in this test, not imputed or guessed at.
- No multiple-testing correction is applied within this test file — 12 Mann-Whitney tests were run here. A combined Benjamini-Hochberg correction across this and later tests is planned as a separate step (test/item 8 in the overall statistical plan), not done per-test.
- `k_chromosomes_whole_chain`'s result is mechanical/tautological (see Analysis Corner point 1 below) and should not be cited as a substantive finding on its own.
- This test only establishes association (chain size predicts qualification), not causation or mechanism — it doesn't explain *why* bigger chains have more room to complete into large cycles, just that they do.

## 6. Analysis Corner

Step-by-step, what the results actually mean:

1. **`k_chromosomes_whole_chain` shows near-perfect separation** (rank-biserial r ≈ -0.99 to -1.0, p<0.0001, at every threshold/lens). This is **not a real finding** — it's a tautology. A closed cycle can never span more chromosomes than the whole chain touches in the first place, so a chain confined to 1 chromosome is structurally incapable of ever qualifying for chromoplexy, no matter which completion lens is used. Read this column's result as a sanity check that passed, not as evidence.
2. **`n_rearrangements` is the real signal.** Chains that newly qualify for chromoplexy have significantly more rearrangements than chains that don't, most strongly at the strict threshold (median 6 vs. 4, rank-biserial r = -0.60 obligate / -0.52 probable, p<0.0001), and still significant (though weaker) at loose (r = -0.25, p=0.0001). Bigger chains are the ones getting newly counted as chromoplexy-positive.
3. **`n_dangling_ends` is weak and inconsistent** (p ranges from 0.02 to 0.87 across the four lens×threshold combinations, no consistent direction). How "open" a chain is does NOT reliably predict whether it gets newly counted as chromoplexy-positive — only raw chain size does.
4. **The Spearman companion check** (n_dangling_ends vs. achievable span) shows a small negative correlation (rho ≈ -0.11 to -0.12, p<0.05) — chains with more open ends achieve a slightly *smaller* max completed span, not a larger one. Real but small; not the main story here.
5. **Bottom line:** whether a chain gets newly counted as chromoplexy-positive under obligate/probable completion is driven by chain size (`n_rearrangements`), not by how unresolved the chain was (`n_dangling_ends`). Since Baca's own headline chromoplexy criterion is *also* a size cutoff (≥5 rearrangements), this means obligate/probable's "extra" chromoplexy recoveries are confounded with the same variable Baca's own criterion already uses — they are not fully independent structural evidence. This caveat should be stated directly wherever the 21/50 and 24/50 obligate/probable numbers from Phase 3 are reported.
