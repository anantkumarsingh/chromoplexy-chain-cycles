# Test 3: ETS+ vs ETS− Comparison

**Script:** `test3_ets_status_comparison.py`
**Output:** `results/stat_test3_ets_status_comparison.csv`
**Images:** `results/stat_test3_ets_status_patient_level.png`, `results/stat_test3_ets_status_chain_level.png`

## 1. What the test is

An earlier session (before this statistical-testing sub-track existed)
noticed a raw chain-level split — ETS+ chains close into a real cycle
56/131 of the time vs. ETS- chains only 35/235 of the time — but never
formally tested it, and never checked whether the same pattern holds at
the patient level or under obligate/probable completion. Biologically this
matters because ETS+ prostate cancer (driven by the TMPRSS2-ERG fusion) is
mechanistically different from ETS- disease, so if chromoplexy detection
tracks ETS status this closely, it's either confirming a real biological
signal or exposing a hidden confound in how the closure methods work.

**Correction (2026-08-06):** all numbers in this document were regenerated
after fixing a bug in how `ETS_status` was computed project-wide. Every
script previously inferred it from `clinical_phenotypes.csv`'s free-text
`'ETS fusion detected by sequencing'` column via "any detected fusion ->
ETS+," which wrongly classified patient PR-4240 as ETS+ (its fusion is
NRF1-BRAF, not ETS-family). `ETS_status` is now sourced directly from
`mmc5.xlsx` Table S5B's own dedicated `ETS fusion` column
(`load_ets_status_from_mmc5()` in `core/baca_aberration_clinical_analysis.py`).
The chain-level split changed from 58/141 vs. 33/225 to 56/131 vs. 35/235;
every OR/p-value below reflects the corrected data. The substance of every
finding is unchanged — only PR-4240 moved from the ETS+ to the ETS- group.

We used **Fisher's exact test** for the same reason as test 2 — some cells
are small (e.g. only 2 patients are Baca-negative overall, several ETS-
subsets have single-digit positive counts), so the chi-square
approximation isn't reliable. We report **odds ratio with a 95% confidence
interval** (not just the point estimate) as the effect size, using the
standard log-odds normal-approximation formula, with the Haldane-Anscombe
correction (add 0.5 to every cell) whenever any cell is exactly 0 — this
avoids `log(0)` and division-by-zero, which would otherwise happen for
several of these tables (Baca's own criterion, for instance, has zero
ETS-negative patients below the bar).

## 2. What the test does

**Part A (primary, patient level, N=52)** — for each of `real`/`obligate`/
`probable` × `strict`/`loose` (6 flags) plus `baca_chain_has_chromoplexy`
(1 flag) = 7 tests total, builds a 2x2 table of `ETS_status` (ETS+/ETS-)
vs. that flag, runs Fisher's exact test, and computes the odds ratio + 95%
CI.

**Part B (secondary, chain level, N=366)** — reproduces the earlier
`real_has_any_closed_cycle` ETS+/ETS- split directly from the Phase 2 CSV
(confirmed to match the previously-reported 56/131 vs. 35/235 exactly
before trusting anything else in this test), then runs the same Fisher's
exact + odds ratio treatment for `obligate_`/`probable_has_chromoplexy_
strict/loose` at chain level.

## 4. Step-by-step: what the test does

1. Load `results/phase3_patient_chromoplexy_summary.csv` (52 patients) and `results/phase2_obligate_probable_completion.csv` (366 chains).
2. **Part A**: for each of the 7 flags, build the ETS_status × flag 2x2 table across all 52 patients, run Fisher's exact test, compute the odds ratio's 95% CI.
3. **Part B**: for each of the 5 chain-level flags (`real_has_any_closed_cycle` plus `obligate_`/`probable_has_chromoplexy_strict/loose`), do the same across all 366 chains.
4. Write all 12 rows (7 Part A + 5 Part B) to the output CSV.
5. Render two bar charts: patient-level positivity rate by ETS status (7 flags) and chain-level positivity rate by ETS status (5 flags).

## 5. Limitations and Notes

- No multiple-testing correction is applied within this file (12 Fisher's exact tests here, on top of 6 from test 2). A combined Benjamini-Hochberg pass across tests 2, 3, and 4's Fisher tests is planned once test 4 is done — not run yet, so read each p-value here as unadjusted.
- Several patient-level odds ratios are extreme or infinite (e.g. `real/strict`: 0 ETS- patients positive at all) — a direct consequence of small counts in this 52-patient cohort, not a computation issue. The 95% CI is the more informative number in those rows than the odds ratio point estimate.
- `obligate/loose` and `probable/loose` show no significant patient-level association (p=1.0) purely because both groups are near ceiling (23/24 ETS+ and 26/28 ETS- are already positive) — there's almost no room left for the groups to differ, not evidence that ETS status stops mattering at the loose threshold.
- This test establishes association only. It cannot distinguish "ETS+ tumors are mechanistically more prone to real coordinated chromoplexy" from "our closure method is more sensitive to whatever pattern ETS+ rearrangements happen to produce" — that distinction needs biological follow-up, not more statistics on this same data.
- Part B (chain level) chains are not independent observations in the statistical sense — most patients contribute multiple chains — so the chain-level N=366 p-values should be read as descriptive/confirmatory of the patient-level pattern, not as an independent replication with its own full N=366 worth of statistical power.

## 6. Analysis Corner

Step-by-step, what the results actually mean:

1. **ETS+ status is strongly and significantly associated with chromoplexy under real, obligate, and probable at both the patient and chain level** — with one exception (see point 3). At the patient level: `real/strict` OR=inf (p=0.039), `real/loose` OR=6.11 (p=0.0043), `obligate/strict` OR=14.57 (p<0.0001), `probable/strict` OR=7.29 (p=0.0019). At the chain level, every one of the 5 tests is significant at p<0.0001, with odds ratios from 4.27 to 9.15.
2. **This directly confirms and extends the earlier informal chain-level observation** (56/131 ETS+ vs. 35/235 ETS-) — reproduced exactly here — showing the same pattern holds not just for real closed cycles but for obligate and probable completion too, and holds at the patient level, not just chain level.
3. **The one place the pattern disappears is `obligate/loose` and `probable/loose` at the patient level** (p=1.0 both) — but this is a ceiling effect, not a real reversal: 96% of ETS+ patients (23/24) and 93% of ETS- patients (26/28) already qualify at the loose threshold under these lenses, so there's essentially no room left for a group difference to show up. Don't read this as "ETS status stops mattering at loose" — read it as "loose obligate/probable saturates for almost everyone."
4. **Baca's own criterion shows the opposite (non-significant) direction** — `baca_chain_has_chromoplexy` OR=0.000 (technically undefined/near-zero from the Haldane-Anscombe correction), meaning ETS- patients are *slightly* more likely to meet Baca's size criterion (28/28 = 100%) than ETS+ patients (22/24 = 92%), though this is not significant (p=0.208) and driven by only 2 non-qualifying patients total. Baca's chain-size criterion does not show the same strong ETS+ skew that our closure-based criteria do.
5. **Bottom line:** chromoplexy detected via AMG cycle closure (real, obligate, and probable alike) is strongly ETS+-skewed at every threshold except where a ceiling effect masks it, while Baca's own size-based criterion is roughly flat across ETS status. This is a genuinely new, statistically supported finding not previously stated formally anywhere in this project — worth a prominent place in the eventual write-up, and worth investigating biologically (is this the AR/TOP2B-driven mechanism specific to ETS+ tumors making genuinely more coordinated rearrangements, or a property of how the closure algorithm interacts with ETS+ chain topology specifically — this test alone cannot distinguish the two).
