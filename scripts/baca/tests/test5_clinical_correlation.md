# Test 5: Gleason / Pathological Stage Clinical Correlation

**Script:** `test5_clinical_correlation.py`
**Output:** `results/stat_test5_clinical_correlation.csv`
**Images:** `results/stat_test5_gleason_grade_group.png`, `results/stat_test5_pathological_t_stage.png`

## 1. What the test is

This test was blocked in the original statistical plan (Session 1) on two
messy real-world clinical fields, and the encoding decision was made
explicit before writing any code (2026-08-05):

- `Gleason_Score` has 4 patients with a recorded tertiary pattern
  (`3+4;5`, `4+3;5`, `4+5;3`) alongside the usual primary+secondary
  entries, and 2 patients with no Gleason score at all.
- `Pathological_stage` has 2 patients recorded as `Metastatic` (no T-stage
  at all) and 2 with nodal involvement appended (`pT3b N1`, `pT4 N1`).

Decision: Gleason gets encoded as the standard ISUP **Grade Group** using
only the primary+secondary pattern — the tertiary pattern, where present,
does NOT change the base Grade Group number, but its presence is captured
in a separate `has_tertiary_pattern` flag rather than being silently
dropped. Pathological stage gets encoded as an **ordinal T-stage**
(pT2a < pT2b < pT2c < pT3a < pT3b < pT4) with any `N1` suffix stripped into
a separate `has_nodal_involvement` flag. The 2 `Metastatic` patients have
no T-stage to encode at all — per explicit instruction, they are set aside
from the T-stage test (not analyzed here) rather than forced onto the
ordinal scale, and flagged with `is_metastatic=True` for visibility.

We used **Mann-Whitney U** (as in tests 1 and elsewhere) because Grade
Group and T-stage are small ordinal scales (1-5 and 1-6 respectively), not
continuous/normal, and the flag groups are unequal in size. We report
rank-biserial effect size alongside the p-value, same as test 1.

## 2. What the test does

For each of `real`/`obligate`/`probable` × `strict`/`loose` (6 flags) plus
`baca_chain_has_chromoplexy` (1 flag) = 7 flags, and each of the 2 encoded
ordinal clinical variables (Gleason Grade Group, T-stage), compares the
clinical variable between the flag's positive and negative patient groups
with Mann-Whitney U, reporting the medians and rank-biserial effect size.
14 tests total (7 flags × 2 clinical variables).

## 3. CSV column reference

| Column | Meaning | Source |
|---|---|---|
| `clinical_variable` | `gleason_grade_group` or `pathological_t_stage` | generated by this script |
| `flag` | the chromoplexy flag column being compared | `phase3_patient_chromoplexy_summary.csv` |
| `lens` | `real`, `obligate`, `probable`, or blank (for `baca_chain_has_chromoplexy`) | same |
| `threshold` | `strict`/`loose`, or blank where not applicable | same |
| `n_flag_pos` / `n_flag_neg` | patients with the flag True / False, after dropping missing clinical data | derived |
| `median_flag_pos` / `median_flag_neg` | median clinical-variable value in each group | derived |
| `U_statistic` | Mann-Whitney U statistic | `scipy.stats.mannwhitneyu` |
| `p_value` | two-sided p-value | `scipy.stats.mannwhitneyu` |
| `rank_biserial_r` | Mann-Whitney effect size, -1 to +1 | computed as `1 - 2U/(n1*n2)` |

## 4. Step-by-step: what the test does

1. Load `results/phase3_patient_chromoplexy_summary.csv` (52 patients).
2. Encode `Gleason_Score` → `grade_group` (base primary+secondary only) + `has_tertiary_pattern` + `tertiary_grade`; 2 NaN patients get `grade_group=None`.
3. Encode `Pathological_stage` → `t_stage_ordinal` (N1 suffix stripped) + `has_nodal_involvement` + `is_metastatic`; the 2 Metastatic patients get `t_stage_ordinal=None`.
4. For each of the 7 flags, run Mann-Whitney U comparing `grade_group` between flag-positive and flag-negative patients (dropping any patient with missing `grade_group`).
5. Repeat step 4 for `t_stage_ordinal` (dropping the 2 Metastatic patients along with the usual missing-data exclusions).
6. Write all 14 rows to the output CSV.
7. Render two 2×4 grids of box plots (one per clinical variable), one panel per flag, comparing the +/- groups visually.

## 5. Limitations and Notes

- **The 2 Metastatic-stage patients are excluded from the T-stage test entirely**, per explicit instruction — "leave them be, we will analyze them later." This is a deliberate, noted exclusion, not a silent drop: `is_metastatic` is a real column in the encoded data, just not used in any hypothesis test here.
- No multiple-testing correction is applied within this file (14 Mann-Whitney tests). Combined with tests 2-4, this brings the running total to 39 hypothesis tests without correction — the planned combined Benjamini-Hochberg pass (see tests 2-4's Limitations sections) should eventually cover this test's p-values too.
- A separate Spearman correlation between each flag (as 0/1) and the ordinal clinical variable was considered but deliberately not run — for a binary-vs-ordinal comparison, Spearman's rho and the rank-biserial effect size already reported here carry essentially the same information, so running both would inflate the test count without adding a genuinely new angle.
- `has_tertiary_pattern` (4 patients) and `has_nodal_involvement` (2 patients) are captured as columns but not separately tested against the chromoplexy flags in this test — both are too rare in this cohort (4 and 2 patients respectively) for any test to have meaningful power, and were out of scope for what was asked here.
- Grade Group and T-stage are ordinal, not interval, scales — medians and Mann-Whitney are appropriate, but treating the numeric gaps between grades/stages as equal-sized (e.g. for a Pearson correlation) would not be.

## 6. Analysis Corner

Step-by-step, what the results actually mean:

1. **None of the 14 tests reach statistical significance** — every p-value is above 0.14, most well above 0.3. This is a genuine null result, not a case of the test failing to run: Gleason grade and pathological T-stage, at least as encoded here, show no detectable association with any of our chromoplexy calls or with Baca's own criterion in this 52-patient cohort.
2. **Effect sizes are small-to-moderate but consistently non-significant** — the largest rank-biserial magnitudes are around -0.30 (`obligate/loose`, `probable/loose`, and `baca_chain_has_chromoplexy` vs. Grade Group; `baca_chain_has_chromoplexy` vs. T-stage at -0.323), but none clear the bar given the sample sizes involved.
3. **Direction is at least consistent for T-stage**: every single flag shows chromoplexy-positive patients with a numerically *higher* median T-stage than negative patients (medians of 3.5-4.0 vs. 3.0-4.0) — a plausible, biologically sensible direction (more advanced local disease, more chromoplexy) even though none of it reaches significance here.
4. **Grade Group shows no consistent direction** — medians are 2.0 for both groups in most comparisons, with only small, inconsistent effect sizes.
5. **Bottom line:** in this cohort, there is no statistically demonstrable relationship between chromoplexy status (by any of our lenses, or Baca's) and either Gleason grade or pathological T-stage. This should be reported as a genuine negative finding, not omitted — it argues against chromoplexy being simply a marker of more aggressive disease stage/grade in this dataset, at least at the sample size available (N=52, and often much smaller once split into flag-positive/negative subgroups). A larger cohort would be needed to rule out a small real effect, particularly for the T-stage direction noted in point 3.
